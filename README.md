- Chaque dossier contient son propre `index.html` et, si nécessaire, ses ressources publiques.
- Les politiques de chaque application restent distinctes et doivent correspondre à son fonctionnement réel.
- Contact commun Android : `ovnis.app@gmail.com`.
- Conserver le code des applications, APK/AAB, clés et mots de passe dans leurs dépôts privés. Ne pas les copier ici.
