На вашем устройстве

Игры, сохранения, настройки и диагностика остаются на устройстве. Нет учётных записей, рекламного отслеживания и автоматической отправки отчётов. Удаление приложения стирает его личные данные.

Чтобы объединять копии одной игры, приложение вычисляет на устройстве цифровой отпечаток содержимого каждого ROM-файла. Отпечаток остаётся на устройстве.

Доступ к играм

С вашего разрешения Android приложение автоматически ищет игры в общем хранилище. Также можно выбрать отдельный файл или папку. Разрешения можно отозвать в настройках Android. Подтверждение удаления стирает файл ROM.

Обложки из интернета

Поиск по названию выполняется на устройстве. Обложки из сети необязательны. При просмотре и загрузке GitHub или Libretro получают IP-адрес и путь изображения, который может содержать название игры.

Bluetooth-контроллеры

Сопряжением управляет Android. Во время игры Game OverTime получает команды и не сохраняет имя контроллера.

Уведомления · Google Play

Уведомления о начале игры и напоминание через семь дней без игры формируются на телефоне. Даты использования и настройки остаются на устройстве. Через три дня по желанию можно открыть Google Play и оставить отзыв. Трансляцией экрана управляет Android.

Ваши данные и настройки

Если убрать папку из приложения, разрешение на доступ к ней отзывается. Доступ ко всем файлам можно отдельно отключить в настройках Android. При повторном импорте того же ROM-файла сохранённая игра будет доступна, пока данные приложения остаются на устройстве. Эти данные можно очистить в настройках Android.
