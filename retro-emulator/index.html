Sur votre appareil

Les jeux, sauvegardes, préférences et diagnostics restent sur cet appareil. Aucun compte, suivi publicitaire ou envoi automatique de diagnostic. La désinstallation efface les données privées de l’application.

Une empreinte du contenu des ROM est calculée sur l’appareil pour regrouper les copies d’un même jeu. Elle reste sur l’appareil.

Accès aux jeux

Avec votre autorisation Android, la recherche automatique parcourt le stockage partagé pour trouver vos jeux. Vous pouvez aussi choisir un fichier ou un dossier précis. Vous pouvez révoquer ces accès dans Android. Supprimer un jeu après confirmation efface son fichier ROM.

Jaquettes en ligne

Les jaquettes en ligne sont facultatives. Les aperçus et téléchargements transmettent à GitHub ou Libretro l’adresse IP et le chemin de l’image demandée, qui peut contenir le titre du jeu.

Manettes Bluetooth

Android gère l’association. Pendant la partie, Game OverTime reçoit les commandes et ne conserve pas le nom de la manette.

Notifications · Google Play

Les notifications de partie et le rappel après sept jours sans jouer sont gérés sur le téléphone. Les dates d’utilisation et le choix de notification restent locaux. Après trois jours, une invitation facultative peut ouvrir Google Play, qui gère votre avis. Android gère la duplication de l’écran vers le téléviseur.

Vos données et vos choix

Retirer un dossier dans l’application révoque son accès individuel. Le scan de tout le stockage se désactive séparément dans les réglages Android. Si vous réimportez la même ROM, vous retrouvez sa sauvegarde tant que les données de l’application sont conservées. Vous pouvez effacer ces données dans les réglages Android.

Contact

Pour toute question sur vos données, écrivez à l’assistance de Game OverTime.
