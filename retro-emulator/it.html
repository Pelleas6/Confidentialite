Sul tuo dispositivo

Giochi, salvataggi, preferenze e diagnostica restano sul dispositivo. Nessun account, tracciamento pubblicitario o invio automatico. La disinstallazione cancella i dati privati.

Sul dispositivo viene calcolata un’impronta del contenuto di ogni ROM per raggruppare le copie dello stesso gioco. L’impronta rimane sul dispositivo.

Accesso ai giochi

Con la tua autorizzazione Android, la ricerca automatica cerca i giochi nella memoria condivisa. Puoi anche scegliere un singolo file o una cartella. Puoi revocare le autorizzazioni in Android. Confermando l’eliminazione cancelli il file ROM.

Copertine online

Le copertine online sono facoltative. Anteprime e download inviano a GitHub o Libretro l’indirizzo IP e il percorso dell’immagine, che può contenere il titolo. I link si aprono nel browser.

Controller Bluetooth

Android gestisce l’abbinamento. Durante la partita Game OverTime riceve i comandi e non memorizza il nome del controller.

I tuoi dati e le tue scelte

Rimuovere una cartella nell’app revoca il relativo permesso. Puoi disattivare separatamente l’accesso a tutti i file nelle impostazioni di Android. Reimportando la stessa ROM ritrovi il salvataggio finché conservi i dati dell’app. Puoi cancellare questi dati nelle impostazioni di Android.
